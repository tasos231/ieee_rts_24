# Μελέτη Ροής Ισχύος στο Δίκτυο IEEE RTS 24 με pandapower

Το συγκεκριμένο αποθετήριο περιέχει την ανάλυση ροής ισχύος (Power Flow Analysis) του πρότυπου συστήματος **IEEE RTS 24-bus** με τη χρήση της βιβλιοθήκης `pandapower`.

## Περιγραφή Project

- Φόρτωση του πρότυπου δικτύου IEEE RTS 24.
- Τοπολογική απεικόνιση και σχεδίαση μονογραμμικού διαγράμματος (ζυγοί, γραμμές, φορτία, παραγωγή).
- Επίλυση της ροής ισχύος με τη μέθοδο Newton-Raphson.
- Υπολογισμός των απωλειών ενεργού ισχύος στις γραμμές μεταφοράς και στους μετασχηματιστές.
